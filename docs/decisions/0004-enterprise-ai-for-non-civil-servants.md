# 4. GitHub Copilot for Non-Civil Servants

Date: 2026-07-03

Last Updated: 2026-07-03

## Status

Proposed

## Context

Since the launch of GitHub Copilot Enterprise at MOJ, access has been limited to civil servants. There is now a growing need for contractors and managed service providers to use Copilot, particularly because Copilot Enterprise is only permitted on MOJ code repositories.

## Decision

- Allow individual contractors to be assigned licences through MOJ's GitHub Enterprise account.

- Allow managed service providers to deploy GitHub Copilot Enterprise for their staff, adhering to the same enterprise controls and guardrails in place for MOJ's GitHub Enterprise account.

## Consequences

### Positive

- Contractors and managed services can use GitHub Copilot Enterprise on MOJ code repositories.

### Risks

- Managed service providers need to continuously evidence compliance.
